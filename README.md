# Note Taking System
This is a simple Todo list web application made using django that does basic CRUD operations.

## Features
- User authentication
- CRUD operations
- User friendly UI
- SQLite supported

## Tech Stack
- **Backend:** Python, Django
- **Frontend:** HTML, CSS, Bootstrap
- **Database:** SQLite
- **Tools:** Git, VS Code

## Installation
- Clone the repository
- Create and activate virtual environment
- Install dependencies from requirements.txt
- Apply migrations
- Run the server

## Usage 
- Open your browser and go to http://127.0.0.1:8000/
- Create a new account or login 
- Start exploring the features (add task, delete task, complete task, etc)
